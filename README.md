One-line slogan for a Solana wallet agent, entered in the [One-Line Slogan for a Solana Wallet Agent](https://make.fun/bounty/u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e) bounty on [make.fun](https://make.fun).

> Your Solana wallet, finally with a brain: it pays, swaps, and sorts the small stuff itself.

## Run

```sh
node main.ts   # writes the slogan to /output/entry.txt
```

`main.ts` validates the slogan against the bounty gate first: 1–140 characters, at most 20 words, exactly one line.
